class photon_mosaic.segmentation.basesegmentation.BaseSegmentation[source]#

Base class for ROI segmentation backends.

Modelled on SpikeInterface’s BaseSorter: subclasses are never instantiated, they only provide classmethods that photon_mosaic.segmentation.run_segmentation() calls in order:

  1. initialize_folder() / set_params_to_folder() (provided here)

  2. run() – detect ROIs on one contiguous span of epochs and return them as a BaseRois

Subclasses declare method_name (the string users pass as method) and settings_class (their pydantic settings model), and register themselves with register_segmentation_class().
