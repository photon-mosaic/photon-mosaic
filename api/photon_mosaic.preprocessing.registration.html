Settings shared by every motion correction backend.

Only options that are meaningful for any backend live here; algorithm specific parameters belong on the subclass (e.g. Suite2pRegistrationSettings), which is also expected to set its own env_prefix. The prefix here is deliberately not empty: without it these fields would read bare DEVICE / BATCH_SIZE from the environment.

Shared fields carry one meaningful name; each field’s description records what the underlying library calls it (suite2p maxregshiftNR, CaImAn pw_rigid, …).

class photon_mosaic.preprocessing.registration.RegisterImaging(imaging, motion, method='suite2p', **kwargs)[source]#

Apply pre-computed motion correction on-the-fly, whatever the backend.

Dispatch is by method (like Motion.compute()), defaulting to "suite2p", and resolved through photon_mosaic.core.get_registration_class(), so this class imports no backend itself.

class photon_mosaic.preprocessing.registration.RegisterImagingEpoch(parent_imaging_epoch, motion, epoch_index, **kwargs)[source]#

Epoch view that applies stored motion on read; backends implement _correct_plane().

Holds the bookkeeping every backend shares – frame-bound checks, plane selection, output allocation – so a backend’s epoch class is only the per-plane correction.
