merged_with_suite2p_defaults()[source]#

Return suite2p’s installed detection defaults overlaid with our overrides.

Used to source per-algorithm sub-dicts (sparsery_settings, sourcery_settings, cellpose_settings) without hard-coding them and to forward denoise/highpass_time etc. to the inner calls.

class photon_mosaic.segmentation.suite2p_segmentation.Suite2pSegmentation[source]#

Suite2p ROI detection, streamed from the imaging object.

Frames are pulled lazily via BaseImagingEpoch.get_series() and stream-binned in place, so the full raw movie is never materialised. Returns a Suite2pRois holding every plane’s suite2p stat.
