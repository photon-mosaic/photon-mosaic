photon-mosaic#

Modular, extensible Python API for flexible analysis of multi-photon imaging data, part of the broader PhotonMosaic framework.

Note

photon-mosaic is experimental software in its early stages.

Things may change significantly.

We welcome feedback from users: get in touch with the core developer team via zulip chat or open a GitHub issue. It would be great to hear from you!

Check out the User Guide for instructions about using photon-mosaic.
